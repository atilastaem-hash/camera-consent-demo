آزمایش دوربین با رضایت صریح کاربر — Windows 11 + VS Code
========================================================

این پروژه پس از آن‌که کاربر متن انگلیسی را می‌خواند، تیک رضایت را می‌زند
و مجوز دوربین مرورگر را تأیید می‌کند، یک عکس می‌گیرد و آن را به کامپیوتر
آزمایشگر می‌فرستد. عکس در گوشی پیش‌نمایش داده نمی‌شود. استفاده از دوربین
در مرورگر قابل مشاهده است و صفحه به‌روشنی درباره عکس‌برداری و ارسال آن اطلاع می‌دهد.

۱) فایل ZIP را استخراج کن و پوشه camera_consent_demo را در VS Code باز کن.

۲) در ترمینال VS Code این دستورات را اجرا کن:

   py -m venv .venv
   .venv\Scripts\activate
   py -m pip install -r requirements.txt
   py app.py

۳) ترمینال را باز نگه دار. سرور محلی روی http://127.0.0.1:5000 اجرا می‌شود.

۴) برای ساخت لینک HTTPS موقت، Cloudflare Tunnel (cloudflared) را از صفحه رسمی
   زیر نصب کن:
   https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/

۵) در ترمینال دوم VS Code اجرا کن:

   cloudflared tunnel --url http://127.0.0.1:5000

۶) Cloudflare یک لینک HTTPS موقت با دامنه trycloudflare.com چاپ می‌کند.
   همان لینک را فقط برای شرکت‌کننده آزمایش بفرست.

۷) شرکت‌کننده لینک را در مرورگر گوشی باز می‌کند، متن انگلیسی را می‌خواند،
   تیک رضایت را می‌زند، دکمه موافقت را می‌فشارد و مجوز دوربین را تأیید می‌کند.
   پس از شمارش دوثانیه‌ای، عکس خودکار گرفته و ارسال می‌شود.

۸) عکس‌ها در پوشه captures همین پروژه ذخیره می‌شوند.

نکات مهم:
- هیچ برنامه‌ای روی گوشی لازم نیست؛ مرورگر به‌روز کافی است.
- کامپیوتر باید روشن و به اینترنت متصل بماند و هر دو ترمینال باز باشند.
- لینک Quick Tunnel موقت است و با بستن cloudflared از کار می‌افتد.
- لینک را عمومی منتشر نکن؛ هر کسی که آن را داشته باشد می‌تواند صفحه را باز کند.
- برای پایان آزمایش، پنجره‌های سرور و cloudflared را با Ctrl+C متوقف کن.
- اگر Windows Firewall پرسید، فقط دسترسی لازم را برای شبکه مورد استفاده تأیید کن.
- این پروژه برای آزمایش با اطلاع و رضایت فرد حاضر طراحی شده است.
